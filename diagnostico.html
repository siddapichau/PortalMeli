Diagnóstico da integração n8n

Testa, a partir deste navegador, se os webhooks do n8n estão publicados e respondendo no formato que as telas esperam. Nenhum dado é gravado: a rota de escrita é chamada com payload vazio de propósito.

RotaEstadoDetalhe

O que fazer com o resultado

  1. NÃO PUBLICADO: abra o workflow no n8n, confirme o path e ligue o botão Active. Webhooks de teste (/webhook-test/) não servem para o portal.
  2. CORS: se o navegador acusar bloqueio, libere a origem do portal no nó Webhook (Allowed Origins) ou no proxy.
  3. Contrato: ler-planilha deve devolver JSON com abas/dadosCompletos; atualizar-celula deve devolver success:true ou erro.
  4. Planilha: confirme que a credencial do Google Sheets acessa a cópia de teste e que a coluna Planilha da aba Paginas aponta para ela.
